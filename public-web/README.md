# Seek Unique Timer - UI Demo

✨ A stylish productivity timer interface.

## 🔗 Live Demo
https://codewithsuraj0007.github.io/seek-unique-timer/

## Features
- 🕒 Beautiful timer UI
- 📊 Productivity-focused design
- 🎨 Modern visuals and animations
- 💼 Multiple activity types (Work, Meeting, Lunch, Break, SMM, Activity)

## Note
This is a static UI demo. Backend features (Firebase, Electron, Slack integration) are disabled for security and simplicity.

## Deployment
This demo is deployed using GitHub Pages from the `/public-web` folder.

## Full Version
The full desktop application includes:
- Firebase authentication and data persistence
- Electron desktop integration
- Slack notifications
- Admin panel
- Productivity tracking
- Attendance management
